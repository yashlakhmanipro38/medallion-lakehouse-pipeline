1. ROW_NUMBER — Deduplication

Picks the latest record per order_id, dropping stale duplicates.

SELECT *, ROW_NUMBER() OVER( PARTITION BY order_id ORDER BY _ingested_at DESC ) AS rn -- keep only rn = 1

2. RANK — Top Customers by Spend

Ranks customers within each region by total order value.

SELECT customer_key, region, SUM(order_amount) AS total_spend, RANK() OVER( PARTITION BY region ORDER BY SUM(order_amount) DESC ) AS spend_rank FROM silver_orders JOIN silver_customers

3. LAG / LEAD — Period-over-Period Change

Compares each day's revenue to the previous and next day within each region.

SELECT order_date, region, daily_revenue, LAG(daily_revenue) OVER( PARTITION BY region ORDER BY order_date ) AS prev_day_rev, daily_revenue - LAG(daily_revenue) OVER(...) AS change, SUM(daily_revenue) OVER( PARTITION BY region ORDER BY order_date ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW ) AS running_total

Orders ↔ Customers JOIN

Enriches each clean order with customer region and name via an inner join on customer_key.

SELECT o.order_id, o.order_date, o.order_amount, c.customer_name, c.region FROM silver_orders o INNER JOIN silver_customers c ON o.customer_key = c.customer_key
